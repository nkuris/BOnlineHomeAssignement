# ERD render instructions

This repository contains `docs/ERD.mmd` (Mermaid ERD). To render to PNG locally:

- Option 1: Use the Mermaid CLI (mmdc).
  - Install: `npm install -g @mermaid-js/mermaid-cli`
  - Render: `mmdc -i docs/ERD.mmd -o docs/ERD.png`
- Option 2: Use VS Code Mermaid Preview extension and export.

If rendering is not possible in your environment, leave `docs/ERD.png` as a placeholder and update it later.
